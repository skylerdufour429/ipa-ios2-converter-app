# IPA to iOS 2.0 Converter Web App

This is a **GitHub Codespaces-ready** static web application template that can be served via **GitHub Pages**.

## Features
- Complete static HTML5/CSS3 frontend layout.
- Mock conversion pipeline for processing `.ipa` payloads.
- Fully configured `.devcontainer/devcontainer.json` for immediate execution in GitHub Codespaces.

## Launching in Codespaces
1. Upload this repository to GitHub.
2. Click **Code** -> **Codespaces** -> **Create codespace on main**.
3. Run `browser-sync start --server --port 3000 --watch` in the terminal to view your live app.

## Deploying to GitHub Pages
1. Go to your repository settings.
2. Select **Pages** under the "Code and automation" sidebar section.
3. Configure the build source to **Deploy from a branch** and select `main`.
